# نوا | Nova Landing Page

یک سایت تک‌صفحه‌ای (Landing Page) مدرن و حرفه‌ای با تم دارک، انیمیشن‌های زیبا و طراحی واکنش‌گرا.

## ✨ ویژگی‌ها

- 🌙 تم کاملاً دارک با رنگ‌بندی مدرن بنفش/آبی
- 🎯 هدر حرفه‌ای با افکت شیشه‌ای
- 🚀 هیرو متحرک با حلقه‌های چرخان و کارت‌های شناور
- ✨ انیمیشن‌های اسکرول و افکت‌های هاور
- 🖼️ گالری تصاویر با گوشه‌های نرم
- 📱 کاملاً ریسپانسیو برای موبایل و تبلت
- ⚡ بدون نیاز به دیتابیس یا سرور بکند — استاتیک و سریع

## 🚀 استفاده محلی

فقط کافیست فایل `index.html` را در مرورگر باز کنید. نیازی به هیچ پیش‌نیازی نیست.

```bash
# یا با یک سرور محلی ساده:
python3 -m http.server 8080
# سپس به http://localhost:8080 بروید
```

## 🌐 انتشار

برای انتشار روی دامنه رایگان می‌توانید از سرویس‌های زیر استفاده کنید:

- **Netlify Drop**: https://app.netlify.com/drop (فقط کشیدن و رها کردن)
- **Vercel**: https://vercel.com
- **GitHub Pages**: از طریق Settings → Pages
- **Cloudflare Pages**: https://pages.cloudflare.com

## 📝 ویرایش

- **متون**: فایل `index.html` را با یک ویرایشگر متن باز کنید
- **رنگ‌ها و استایل**: متغیرهای بالای فایل `styles.css` را تغییر دهید
- **عکس‌های گالری**: در `index.html` به جای `background: linear-gradient(...)` از `background: url('images/photo.jpg')` استفاده کنید

## 🛠 تکنولوژی‌ها

- HTML5
- CSS3 (با انیمیشن و Gradient)
- JavaScript خالص (بدون کتابخانه خارجی)
- فونت فارسی Vazirmatn از Google Fonts
